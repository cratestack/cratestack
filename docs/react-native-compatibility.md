# React Native compatibility

This page tracks React Native compatibility evidence for the published
`@cratestack/*` npm packages.

Compatibility is verified against real React Native / Expo applications. Source
inspection alone is not enough to mark a package as working.

## Test environment

- Expo: `57.0.20`
- React Native: `0.86.3`
- Platform: Android physical device (Google Pixel 9)
- App launch command: `npx expo start --tunnel`
