Sync Notes cratestack-sync prototype

Three devices, each with its own SQLite database on OPFS (a Rust/wasm worker), syncing with one Postgres server. Writes land locally first, so they work offline. They replay on the server under the schema's policies, and changes come back through a commit-ordered change log.
